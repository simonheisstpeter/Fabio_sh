4. IPTABLES FIREWALL (STATEFUL INSPECTION TEXTFILE TEMPLATE)
-------------------------------------------------------------------------------
Erstelle die Datei mit: nano firewall-text.sh (Nur zum Abgeben!)

```bash
#!/bin/bash
# --- 1. VARIABLEN DEFINIEREN ---
EXT_IF="ens33"            # Externes Interface (oder ens34)
INT_NET="10.11.12.0/24"   # Internes Subnetz (oder 172.16.6.0/24)
EXT_IP="192.168.80.3"     # Statische externe IP deines Gateways
WEB_IP="10.11.12.2"       # IP des Webservers
DNS_IP="10.11.12.3"       # IP des DNS-Servers
MAIL_IP="10.11.12.4"      # IP des Mailservers

# --- 2. FLUSH & RESET ---
iptables -F
iptables -X
iptables -t nat -F

# --- 3. DEFAULT POLICIES (DROP) ---
iptables -P INPUT DROP
iptables -P FORWARD DROP
iptables -P OUTPUT ACCEPT

# --- 4. LOOPBACK & STATE TRACKING ---
iptables -A INPUT -i lo -j ACCEPT
iptables -A INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT
iptables -A FORWARD -m state --state ESTABLISHED,RELATED -j ACCEPT

# --- 5. FREIGABEN FÜR INTERNE HOSTS (FORWARD) ---
iptables -A FORWARD -p tcp -d $WEB_IP --dport 80 -j ACCEPT
iptables -A FORWARD -p udp -d $DNS_IP --dport 53 -j ACCEPT
iptables -A FORWARD -p tcp -d $DNS_IP --dport 53 -j ACCEPT
iptables -A FORWARD -p tcp -d $MAIL_IP --dport 25 -j ACCEPT

# --- 6. AUSGEHENDER TRAFFIC RESTRIKTIONEN ---
# Variante A (Gruppe 04-A, 04-B, 05-A): Nur HTTPS ins Internet erlaubt
iptables -A FORWARD -s $INT_NET -p tcp --dport 443 -j ACCEPT

# Variante B (Gruppe 05-B): Nur SSH ins Internet erlaubt
# iptables -A FORWARD -s $INT_NET -p tcp --dport 22 -j ACCEPT

# --- 7. NAT / ROUTING (POSTROUTING MIT SAUBEREM SNAT) ---
iptables -t nat -A POSTROUTING -s $INT_NET -o $EXT_IF -j SNAT --to-source $EXT_IP

# --- 8. PORT-FORWARDING / INCOMING (PREROUTING / DNAT) ---
iptables -t nat -A PREROUTING -i $EXT_IF -d $EXT_IP -p tcp --dport 80 -j DNAT --to-destination $WEB_IP:80
WIRESHARK BEWEISFÜHRUNG (DISPLAY-FILTER QUICK REFERENCE)

HTTP-Traffic nachweisen:
Filter: http -> Achte auf "GET / HTTP/1.1" vom Client und "200 OK" vom Server.

DNS-Traffic nachweisen:
Filter: dns -> Zeigt "Standard query A www.ant.lab" und die Antwort mit der IP.

DHCP-Vergabe nachweisen:
Filter: bootp -> Such nach dem klassischen DORA-4-Way-Handshake:

DHCP Discover | 2. DHCP Offer | 3. DHCP Request | 4. DHCP Ack

E-Mail-Verkehr nachweisen:
Filter: smtp || imap -> SMTP protokolliert das Senden, IMAP das Lesen.
